# Python File Organizer

A simple Python automation tool that organizes files
into folders based on their file extensions.

## Features

- Organizes TXT files
- Organizes PDF files
- Organizes images
- Organizes documents
- Organizes music and videos
- Unknown files go to "another files"
- Existing folders are skipped

## Technologies

- Python
- os module
- shutil module

## How to Run

```bash
python3 file_organizer.py
